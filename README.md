A modern and extensible desktop text editor built with **Electron, React and TypeScript**.  
The project focuses on clean architecture and demonstrates several important software design patterns.

**Key Features**
- File browsing, opening and saving
- Code editor powered by CodeMirror
- Syntax highlighting for JavaScript, TypeScript, Java, Assembly and Plain Text
- Real-time notification system
- Clean dark-themed coding interface

**Architecture & Design Patterns**
- **Command Pattern** for file operations such as save, create file and create directory

### 🍳 CHEF Programming Language

A cooking-themed programming language where code reads like a recipe.  
This project includes a syntactic analyzer and an AST-based interpreter using **Flex, Bison/Yacc and C/C++ concepts**.

**Key Features**
- Variable and constant declarations
- Integer, float, boolean, string and char support
- Arithmetic, comparison and logical operators
- If / else-if / else structures
- While loops
- Function definitions and function calls
- Input / output operations
- Exception handling system

**Example Concepts**
- `ingredient` for variable declaration  
- `recipe` for function definition  
- `serve` for output  
- `stir` for loop  
- `heat / reheat / burn` for conditionals  

**Tech Stack:** Flex, Bison/Yacc, C/C++, Compiler Design, AST Interpreter
